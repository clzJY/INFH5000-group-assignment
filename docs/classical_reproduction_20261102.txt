Common contract
All six methods see the same full route, exact ego state, current pedestrian poses/derived velocities and current static TestObject planar boxes. RGB is recording only.
Forward-only, cruise<=3m/s, steering slew<=1.5 normalized units/s, same low-level speed adapter and finite physical wheel brake hold.
0.02s native physics x5 =0.1s decision. Horizon600=60s. No ego position/velocity overwrite.
Strict arrival =native flag AND endpoint distance<=2m. Earlier native flags are retained separately.
Before stepping: route length and initial endpoint distance must both be>=5m. Invalid generated tasks are retained without replacement.
Pedestrian contact =crash_human OR crash_vehicle, because native pedestrian bodies are tagged as vehicles; other moving traffic is disabled.
Any-contact-free goal also excludes object/building/sidewalk contact. Keep raw flags.
New primary near exposure: native planar oriented-box gap<1m at sampled post-step poses, divided by observed navigation duration. Old circle-proxy exposure is secondary and cannot be compared numerically as the same measure.
Physical speed>20m/s is a retained anomaly flag, never a post-hoc exclusion.
Static TestObject footprints exclude road/curb meshes; native contact and out-of-road termination remain authoritative outcomes.

Methods
pp: shared pure pursuit + endpoint speed regulation + common static guard; no pedestrian yield.
rpp: RPP-inspired curvature/proximity regulation + 1s fixed-curvature projection against current pedestrian occupancy; no ROS costmap/plugin.
distance: regulated tracking and current pedestrian-gap speed scaling (0.25 to1.5m).
forecast_static: route-conditioned speed candidates with zero pedestrian velocities.
forecast: exact same candidate procedure with measured constant pedestrian velocity.
dwa: bounded velocity/steering search using predicted moving pedestrians, progress/route/clearance/control costs. Ackermann adaptation, not canonical original synchro-drive DWA or an official Nav2 reproduction.
The inherited positive-cap adapter labels every moving command SLOW; interpret cap/reason, not the label alone, as a yield intervention.
All forecast thresholds/horizons/accel/brake settings are fixed in configs/classical_frozen_20261102.json.
Forecast compares stopping as well as moving. No feasible buffer ->explicit diagnostic; an overlap-reducing escape heuristic may still have collision risk. Prediction is approximate and sampled; route rollouts omit steering slew and detailed native wheel transients. This is not a safety proof.
