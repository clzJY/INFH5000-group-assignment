# 训练过程、实际提升与对比方法

本轮能确认的提升主要来自新的几何局部规划。训练后的视觉语言模型学会了部分动作选择，但尚未超过几何规划器。下面把训练、对比和结论分开说明，方便组员理解和复现。

## 模型如何训练

采用已有的 **SmolVLM2-500M** 多模态模型，让它学习当前应该选择哪条局部轨迹。训练属于监督式模仿学习，没有进行强化学习，也没有通过大量导航试错更新模型。

1. 在原生三维模拟器中采集当前相机图像、局部地图和固定任务指令。局部地图来自模拟器提供的几何状态，是特权信息，并非模型从街景图像独立识别出的地图。
2. 几何规划器预测候选轨迹与行人、障碍物的关系，选择动作作为标签。这些标签来自预测评分，并非把每个候选动作都在原生模拟器中执行后获得的真实反事实结果。
3. 用图像、地图和指令预测动作标签 A–F。A–E 对应五条横向偏移轨迹（−1.5、−0.75、0、+0.75、+1.5 米），F 对应停车。
4. 将训练后的模型接回模拟器。模型每秒提出一次动作选择；几何执行层每 0.1 秒重新检查。建议不可行时，回退到几何选择；没有可行候选时刹车。实际运动由原生物理执行。

| 项目 | 实际设置 |
| --- | --- |
| 输入 | 单张当前相机图像、局部地图、固定英文任务指令 |
| 训练数据 | 598 个决策样本，不是 598 条完整导航任务 |
| 验证数据 | 304 个决策样本，与训练按完整场景种子分离 |
| 训练方式 | Low-Rank Adaptation（LoRA，低秩适配），冻结基础模型 |
| 适配位置 | 视觉与语言注意力的 query/value 投影 |
| 可训练参数 | 1,114,112，rank 8、alpha 16 |
| 训练目标 | 带类别权重的交叉熵，模仿几何规划器选择 |
| 优化 | AdamW，学习率 0.0003，批量大小 4，10 轮 |
| 训练重复 | 种子 0、1、2；另训练一个排除弯道场景的模型 |
| 检查点选择 | 根据验证准确率与六类平均召回率的均值，不使用正式测试结果 |
| 计算资源 | 本地 RTX 5880；模型环境与原生模拟器环境分开 |

主种子的验证标签准确率为 **77.3%**，六类平均召回率为 **47.5%**。始终选择最多数标签的参照准确率为 54.6%。这些数值衡量模仿教师的程度，不是导航到达率。

这套系统是 **VLM 引导的分层导航**：模型参与高层动作选择，几何模块负责候选检查和低层执行。它尚不具备完整端到端 VLA 或开放语言指令导航的验证证据。

## 对比方法分别检验什么

所有主比较使用共享参考路线。RPP、DWA、MPPI 均为本项目的改编实现，不是其官方完整复现。

| 方法及代码名 | 实际做法 | 检验的问题 |
| --- | --- | --- |
| Regulated Pure Pursuit-inspired，`rpp` | 跟随路线，根据转弯、邻近距离和短期碰撞检查调速/停车 | 经典受约束的路线跟随是否足够？ |
| 路线内速度预测，`forecast` | 预测行人与机器人沿途的占地，选择速度，不主动增加横向候选 | 只改变速度能解决多少问题？ |
| Dynamic Window Approach-style，`dwa` | 搜索局部转向和运动指令 | 先前的局部控制搜索在共享路线上表现如何？ |
| Model Predictive Path Integral-style，`mppi` | 对 96 条有界短期控制序列采样、评分和加权 | 更灵活的采样控制是否有效？ |
| 几何局部规划器，`lattice` | 从五条横向候选轨迹和停车中，按可行性与几何评分选择 | 不使用神经模型，这套候选与执行结构能做到什么？ |
| 未适配 VLM，`vlm` | 直接用预训练模型选择六个动作标签，保留几何检查和回退 | 模型是否可以直接使用本项目的动作定义？ |
| 适配 VLM，`lora` | 完成视觉/语言 LoRA 模仿训练，再选择同样的动作 | 任务适配是否有效，能否超过几何选择？ |

模型和几何选择器使用相同的候选、几何检查和回退机制。但几何选择器显式使用行人速度，模型只看到单帧和当前地图，没有显式速度标注或视觉历史。因此，比较包含观察表示的差异，不是纯粹的神经架构比较。

RPP、路线内速度预测和 DWA 保留原先的静态物体检查，没有获得新候选库的可通行区域过滤。因此，它们与新几何方法的比较检验的是局部规划组合，而非仅一个单独模块。

PPO 没有作为本轮主比较，因为现成策略的任务与当前测试并不匹配。原作业中的零速度消融仍保留在历史结果中，没有混入这次七方法的统计。

## 实际提升在哪里

下表每个方法均使用相同的 **120 组自然街景条件**。严格到达要求原生到达标志和距离终点不超过 2 米同时满足；无接触到达还要求整个回合没有记录到接触。

| 方法 | 严格到达 | 无接触到达 |
| --- | ---: | ---: |
| RPP-inspired | 91/120 | 59/120 |
| 路线内速度预测 | 97/120 | 62/120 |
| DWA-style | 85/120 | 58/120 |
| MPPI-style | 65/120 | 54/120 |
| 新几何局部规划器 | **99/120** | **79/120** |
| 未适配 VLM | 0/120 | 0/120 |
| 适配 VLM，主种子 | 83/120 | 68/120 |

**几何局部规划获得了明确收益。** 相比路线内速度预测，无接触到达提高 **14.17 个百分点**，配对场景分组 bootstrap 的 95% 区间为 **[6.67, 21.67]**。出现行人接触的回合从 49 降至 31。在双方均到达的 93 组条件中，它平均慢约 **0.45 秒**，主要收益体现在完成与接触指标。这是候选轨迹、约束和执行方式组合的效果，尚未拆开各子模块的贡献；所有主比较共享的新参考路线不构成这一差异的单独证据。

**模型适配让动作选择具备任务执行能力，但没有带来额外的规划优势。** 主种子无接触到达为 68/120，比几何选择器低 **9.17 个百分点**，主配对 95% 区间为 **[−16.67, −2.50]**；在双方均到达的 80 组条件中，平均慢约 **12.23 秒**。未适配模型的失败说明它没有直接有效使用这套动作定义，并不代表预训练模型在所有导航任务中无效。

适配模型比路线内速度预测多 6 次无接触到达，但该差异为 +5 个百分点，配对区间 **[−4.17, 14.17]** 包含零；两者执行结构也不同，不能据此把收益单独归因于 VLM。

三个训练种子的无接触到达分别是 **68、18、58 /120**，全部低于几何选择器的 79/120。主种子预先固定为 0，没有从测试结果中挑选最好模型。

## 模型为什么还不够好

已经观察到的限制包括：训练场景少、连续画面相关、直行和停车标签占比高，以及教师显式使用速度而单帧模型没有相同信息。验证集中，某个横向动作在十个样本上的召回率为零。它们提供了可能解释，尚未通过独立实验逐一确认因果关系。

模仿教师本身也不意味着超过教师。当前没有实际反事实执行、人类反馈或强化学习信号来判断教师选择之外的动作是否更好。

另外 24 组输入消融条件中，完整输入、去掉 RGB、去掉全部图像、简化指令的无接触到达分别为 14、13、15、5 /24。无图像模型的全部 1,795 次提议都选择中心轨迹，实际执行仍受几何检查约束，越界暴露也更高。因此不能将这些小样本结果解释为“视觉无用”或“各模态都有独立收益”。
